# studyroom

Research studies, one directory per study. Each study has problem documents
(definitions, formats, surveys, plans) and implementations in Python and Rust
that share the same on-disk formats. Start with a study's `README.md`.

| Study | What |
|-------|------|
| [`001/`](001/README.md) | Trace analysis for asynchronous multi-threaded block I/O: problem documents, Python reference implementation, model-written linearizers |

Agent guidance is in `AGENTS.md`.
